# Task Protocol

Each task lives under:

```text
.ai/tasks/<TASK_ID>/
```

`TASK_ID` may contain letters, numbers, dash, underscore, and dot. The orchestrator rejects path-like or empty IDs.

## Files

- `task.json`: task state, timestamps, rework counters, role metadata, and history.
- `brief.md`: human-facing task brief.
- `gemini-context.md`: compressed context prepared by Gemini.
- `codex-report.md`: implementation summary from Codex.
- `patch.diff`: patch preview or generated diff artifact.
- `grok-review.md`: red-team review from Grok Build.
- `final-for-claude.md`: the only file Claude Code should read.
- `claude-decision.md`: final decision output.

## Real Gemini Context Protocol

When explicitly enabled, the Gemini adapter affects only the `context` stage:

```bash
python -m agent_office context <TASK_ID> --real --adapter gemini --timeout 120
```

Inputs:

- `.ai/tasks/<TASK_ID>/task.json`
- `.ai/tasks/<TASK_ID>/brief.md`
- a safe project file-tree summary generated by AgentOffice
- `README.md`, `docs/`, and `AGENTS.md` when present

Output:

- `.ai/tasks/<TASK_ID>/gemini-context.md`

The output must contain:

```text
# Relevant Files
# Why These Files Matter
# Test Entry Points
# Implementation Hints
# Risks
```

If `gemini-context.md` is missing, empty, too unsafe, or missing required sections, the task remains in its previous state and does not transition to `CONTEXT_READY`.

## Real Grok Red-Team Protocol

When explicitly enabled, the Grok adapter affects only the `redteam` stage:

```bash
python -m agent_office redteam <TASK_ID> --real --adapter grok --timeout 120
```

Inputs:

- `.ai/tasks/<TASK_ID>/brief.md`
- `.ai/tasks/<TASK_ID>/codex-report.md`
- `.ai/tasks/<TASK_ID>/patch.diff`

Output:

- `.ai/tasks/<TASK_ID>/grok-review.md`

The output must contain:

```text
# Blocking Issues
# Non-blocking Issues
# Missing Tests
# Security Risks
# Performance Risks
# Verdict
```

If `grok-review.md` is missing, empty, or missing required sections, the task remains in its previous state and does not transition to `REVIEWED`.

## State Machine

```text
CREATED
CONTEXT_READY
IMPLEMENTED
REVIEWED
SUMMARIZED
APPROVED | REQUEST_CHANGES | REJECTED
```

`REQUEST_CHANGES` may return to context or implementation for a bounded number of rework rounds. `APPROVED` and `REJECTED` are terminal states.

## Repeatable Demos

Use `--reset` for a deterministic rerun:

```bash
python -m agent_office run-demo DEMO-FINAL --mock --reset
```

`--reset` deletes only the matching task directory under `.ai/tasks/` after validating the task ID. It does not delete other protocol files or any source code.

Generated task directories are runtime artifacts and are ignored by git.

## Doctor Protocol

Doctor commands do not create or modify task directories:

```bash
python -m agent_office adapters
python -m agent_office doctor
python -m agent_office doctor --json
```

The diagnostic layer checks configuration and project structure only. It does not execute real Codex/Gemini commands and does not read `.env`.
It also reports Grok configuration state without executing `AGENTOFFICE_GROK_CMD`.
